# KCMP AI 도구 — 개선프롬 GPT5.6

Google Sheets의 Google Apps Script에서 소집단 담화 전사 자료를 KCMP(K·C·M·P) 차원으로 분석하도록 돕는 도구입니다.

## 사용 전 준비

1. 4명 내외 소집단 녹음을 전사합니다.
2. Google Sheets의 **1행에 헤더**를 두고, 실제 데이터는 **2행부터** 입력합니다.

| 열 | 내용 |
| --- | --- |
| A | 화자 |
| B | 타임스탬프 |
| C | 발화 |

3. OpenAI Platform에서 결제를 활성화하고 본인의 API 키를 준비합니다.
4. Sheets 메뉴 **AI 코딩 → 1. API키 설정**에서 키를 입력합니다.

API 키는 현재 사용자에게만 저장되며, GitHub·스프레드시트·다른 사용자에게 기록되지 않습니다. API 사용 요금은 키 소유자의 OpenAI 계정에 청구됩니다.

## 권장 실행 순서

1. 헤더 설정
2. 교사·학생 지정
3. 클러스터링
4. 화자별 발화분석
5. K, C, M, P 코딩을 순서대로 실행

K·C·M·P 분석은 Google Apps Script 실행 시간 제한을 피하도록 배치 처리됩니다. **이어서 코딩** 메뉴를 해당 단계가 완료될 때까지 반복 실행하세요.

## 결과 사용 시 주의

자동 코딩 결과는 연구·교육 판단을 보조하는 초안입니다. 최종 사용 전 반드시 원문 전사본과 대조하고, 연구자 또는 교사가 결과와 근거를 검토·수정해야 합니다.

이 저장소는 Google Sheets Editor add-on 배포를 준비하는 개발 단계입니다. 공개 Google Workspace Marketplace 게시 전에는 OAuth 권한, 개인정보 처리 안내, 테스트 배포 및 Google 검토 요건을 추가로 충족해야 합니다.
